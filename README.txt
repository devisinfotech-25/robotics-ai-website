AZ MOBILES / ROBOTICS & AI LAB WEBSITE

PACKAGE CONTENTS
- index.html: Home page
- about.html: About page
- services.html: Products and services page
- contact.html: Contact enquiry page
- style.css: Responsive premium theme and animations
- script.js: Mobile navigation, scroll reveals and contact form UI
- images/: All local image assets used by the website

HOW TO PREVIEW
1. Extract this ZIP folder.
2. Keep the images folder beside all HTML/CSS/JS files.
3. Open index.html in a browser, or use VS Code with Live Server.

PUBLISHING
Upload the complete folder structure to your web host. Do not rename the images folder or its files unless you also update the paths in the HTML.

IMPORTANT
The contact form is front-end only. Connect it to your email/form provider before publishing if you want to receive enquiries. Google Fonts are loaded online; the site otherwise uses local image assets.
